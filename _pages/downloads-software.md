- [PACT](https://github.com/orailix/PACT): pruning and clustering-based visual token reduction for faster vision-language models (CVPR 2025), with LLaVA-OneVision and Qwen2-VL backends
- [MBartCopyGenerator](https://github.com/dbuscaldi/MBartCopyGenerator): mBART-based model for keyword indexing of scientific articles, with a BARThez version adapted to French (NLDB 2022)
- [SKG builder](https://github.com/danilo-dessi/skg): tool to generate a Scientific Knowledge Graph from academic papers
- [TextAnnot](https://github.com/dbuscaldi/TextAnnot): semantic annotation and IR (PostDoc project)
- [Kleis](https://github.com/sdhdez/kleis-keyphrase-extraction): CRF-based keyphrase extractor for scientific literature, also [on PyPI](https://pypi.org/project/kleis-keyphrase-extraction/)
- [YaSemIR](https://github.com/dbuscaldi/YaSemIR): Yet Another Semantic Information Retrieval system
- [SemEval / \*SEM STS task participations](https://github.com/dbuscaldi/SemEval): code used in the STS tasks 2012 and 2013
